Étape 1/3

Installation du terminal

Suivez ces étapes une seule fois par poste de caisse. Durée estimée : 10 minutes.

🖨️ A — Configurer l'imprimante

1

Installer le pilote de l'imprimante

Connectez l'imprimante thermique (USB ou réseau). Installez le pilote fourni par le fabricant (Epson, Bixolon, HPRT…). Vérifiez qu'elle apparaît dans Panneau de configuration → Périphériques et imprimantes.

2

Définir comme imprimante par défaut

Faites un clic droit sur l'imprimante ticket → "Définir comme imprimante par défaut". C'est sur cette imprimante que les tickets seront envoyés automatiquement.

💡 Désactivez "Windows gère mon imprimante par défaut" dans Paramètres → Imprimantes.
3

Tester l'impression

Clic droit sur l'imprimante → "Propriétés de l'imprimante" → "Imprimer une page de test". Le ticket de test doit sortir correctement.

🌍 B — Créer le raccourci Chrome Kiosk

1

Créer un raccourci sur le bureau

Clic droit sur le bureau → Nouveau → Raccourci. Coller la commande suivante :

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app=https://teliphoni.o3app.ma/pos/main
💡 --kiosk-printing = impression directe sans dialog. --app = ouvre Chrome en mode fenêtre sans barre d'adresse.
2

Nommer le raccourci

Donnez-lui le nom "O3 POS Caisse". Double-cliquez dessus pour vérifier que le POS s'ouvre directement.

3

(Optionnel) Démarrage automatique

Pour que le POS démarre avec Windows, copiez le raccourci dans :

C:\Users\[VotreNom]\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup

💤 C — Empêcher la mise en veille

1

Désactiver la mise en veille Windows

Paramètres → Système → Alimentation et veille → Mettre les deux options sur "Jamais".

2

Désactiver l'écran de veille

Clic droit bureau → Personnaliser → Écran de veille → "Aucun".

💡 L'application O3 POS maintient aussi l'écran éveillé automatiquement via l'API Wake Lock du navigateur.

⚡ D — Configurer le terminal dans O3

1

Créer le terminal POS

Dans O3 → Paramètres → Terminaux POS → Ajouter un terminal avec le nom, le code et l'entrepôt associé.

2

Configurer l'imprimante dans le POS

Ouvrez le POS → cliquez sur l'icône ⚙️ en haut à droite du panier → saisissez le nom exact de l'imprimante Windows → cliquez Enregistrer.

💡 Le nom doit correspondre exactement à ce qui apparaît dans "Périphériques et imprimantes".

Guide caissier

Utilisation quotidienne

Tout ce qu'un caissier doit savoir pour utiliser le POS au quotidien.

🌅 Ouverture de caisse

1

Lancer le POS

Double-cliquer sur le raccourci "O3 POS Caisse" sur le bureau. Connectez-vous avec vos identifiants si demandé.

2

Sélectionner le terminal et ouvrir la session

Choisissez votre terminal (ex: POS_1), saisissez le fond de caisse (montant en espèces dans le tiroir), puis cliquez "Ouvrir la session".

💡 Le fond de caisse est généralement 200 MAD ou le montant défini par votre responsable.

🛍️ Faire une vente

1

Ajouter des articles au panier

Trois méthodes : toucher la carte produit dans la grille, scanner le code-barres avec le lecteur USB, ou rechercher par nom dans la barre de recherche.

💡 Pour un produit avec variantes (taille, couleur…), une fenêtre de sélection s'ouvre automatiquement.
2

Modifier la quantité ou le prix

Dans le panier, utilisez les boutons ＋ / − pour ajuster la quantité. Touchez l'icône ✏️ pour modifier le prix unitaire ou appliquer une remise.

3

(Optionnel) Sélectionner un client

Recherchez un client dans la zone "Client" en haut du panier pour gérer les remises personnalisées et les ventes en compte.

4

Valider le paiement

Touchez le bouton de paiement souhaité :
💵 Espèces 💳 Carte 📋 En Compte

Saisissez le montant reçu si paiement espèces → le rendu monnaie est calculé automatiquement → Confirmer.

💡 Le ticket s'imprime automatiquement après chaque vente si l'option est activée.

⏸️ Mettre une vente en attente

1

Mettre en pause et démarrer un nouveau ticket

Touchez le bouton "Tickets" en haut du panier → "Mettre en attente + nouveau ticket". La vente en cours est sauvegardée.

2

Reprendre un ticket en attente

Touchez à nouveau "Tickets" → sélectionnez le ticket en attente dans la liste → il se recharge dans le panier.

🌙 Fermeture de caisse

1

Vérifier les ventes de la journée

Touchez "Ventes" en haut du panier pour voir le récapitulatif : nombre de tickets, total TTC, répartition par mode de paiement.

2

Fermer la session

Cliquez sur "Fermer la session" → saisissez le montant en caisse (espèces comptées) → Confirmer. Un rapport de clôture est généré.

⚠️ Ne fermez pas le navigateur sans fermer la session proprement.

Impression tickets

Configuration de l'impression

Deux modes d'impression disponibles selon la configuration du poste.

ModeComment ça marchePrérequisStatut
🥇 Chrome Kiosk
Recommandé		 Chrome envoie directement sur l'imprimante par défaut Windows. Aucun dialog. Raccourci avec --kiosk-printing + imprimante par défaut configurée Sans installation
⚡ QZ Tray
Avancé		 Impression réseau avancée, plusieurs imprimantes par terminal, impression sur une imprimante non-défaut. Application QZ Tray installée + nom imprimante configuré dans ⚙️ Installation requise
📄 Dialog navigateur
Fallback automatique		 Boîte de dialogue standard du navigateur si les autres modes échouent. Aucun Automatique

⚙️ Configurer l'imprimante dans le POS

1

Ouvrir les paramètres du terminal

Dans le POS, touchez l'icône ⚙️ engrenage en haut à droite du panier.

2

Saisir le nom de l'imprimante

Dans le champ "Imprimante", tapez le nom exact tel qu'il apparaît dans Windows → Périphériques et imprimantes. Exemple :

EPSON TM-T20III Receipt
3

Activer l'impression automatique

Le toggle "Impression automatique" imprime le ticket après chaque vente sans action manuelle.

4

Enregistrer

Touchez "Enregistrer". Le paramètre est mémorisé pour ce terminal.

💡 Si QZ Tray est connecté, un bouton "Test d'impression" apparaît pour valider la configuration immédiatement.

Dépannage

Questions fréquentes

Solutions rapides aux problèmes courants rencontrés sur le terminal de caisse.

🖨️

Le ticket ne s'imprime pas automatiquement

Vérifiez : 1) Chrome est ouvert via le raccourci kiosk (--kiosk-printing) 2) l'imprimante est définie comme "par défaut" dans Windows 3) l'option "Impression automatique" est activée dans ⚙️.

📡

Le POS affiche "Session introuvable" ou redirige vers la connexion

La session a expiré. Fermer et relancer le raccourci Chrome. Si le problème persiste, vider le cache Chrome (Ctrl+Shift+Delete) et se reconnecter.

📦

Un produit n'apparaît pas dans la grille

Vérifiez dans O3 → Produits que le produit est bien marqué "Disponible en POS" et que son stock est > 0 (ou "Vente sans stock" activée). Rafraîchissez la page.

💳

La vente "En Compte" est grisée

Ce mode n'est disponible que si un client de type "En Compte" est sélectionné dans la zone Client du panier et que son encours ne dépasse pas son seuil de crédit.

🔍

Le scanner code-barres ne fonctionne pas

Cliquez d'abord dans la barre de recherche du POS pour l'activer, puis scannez. Le scanner doit être en mode HID (clavier USB). Certains scanners nécessitent une configuration pour envoyer un "Enter" en fin de scan.

🌐

La page se charge lentement

Vérifiez la connexion internet. Le POS nécessite une connexion stable. En cas de WiFi instable, préférez une connexion filaire (câble Ethernet).

⚡

Le point QZ Tray reste gris (non connecté)

QZ Tray n'est pas installé sur ce poste. Ce n'est pas bloquant — l'impression fonctionne via Chrome kiosk. Pour l'impression réseau avancée, téléchargez QZ Tray sur qz.io et installez-le.

🔒

Le bouton Retour du navigateur ne fonctionne pas

C'est normal et voulu ! Le POS bloque la navigation arrière pour éviter les sorties accidentelles. Pour quitter le POS, utilisez le bouton "Quitter POS" en haut à droite.
